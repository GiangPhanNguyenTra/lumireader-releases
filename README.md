# lumireader-releases

Repository chính thức lưu trữ và phân phối các bản phát hành (Releases) của **LumiReader — Ứng dụng Đọc Ebook & Sách nói AI Tiếng Việt Offline**.

> 💡 *Lưu ý: Đây là kho lưu trữ chuyên dụng để đăng tải các tệp cài đặt chính thức và ghi chú cập nhật (Changelog)*

## 📱 Giới thiệu nhanh về LumiReader

**LumiReader** giúp bạn biến mọi cuốn sách điện tử (EPUB, PDF, TXT...) thành sách nói với giọng đọc AI tiếng Việt tự nhiên, hoạt động hoàn toàn **ngoại tuyến (offline)** mà không cần kết nối Internet.
